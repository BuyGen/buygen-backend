# BuyGen Backend

BuyGen is a cloud-native e-commerce platform built using microservices architecture.

This repository serves as the **parent backend repository**, providing:
- Architecture overview
- Service registry
- Infrastructure documentation

## Core Technologies
- Spring Boot
- Spring Cloud Gateway
- Keycloak
- Kafka
- MySQL
- Docker & Kubernetes
- Observability (Prometheus, Grafana)

## Backend Services
See the `services/` directory for individual service repositories.
